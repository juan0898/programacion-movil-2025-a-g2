# EVIDENCIA ACTIVIDAD CREACIÓN DE UN DISEÑO BASADO EN HISTORIAS

## Módulo 1: Historias de Usuarios

El Módulo 1 explica que las **Historias de Usuarios** son descripciones breves y sencillas que capturan lo que un usuario quiere lograr con un producto o servicio. Siguen la estructura:  
**“Como [tipo de usuario], quiero [acción] para [resultado o beneficio].”**  

Su propósito es definir claramente los objetivos del usuario desde su perspectiva, ayudando a priorizar funcionalidades y orientar el diseño hacia soluciones que realmente satisfagan sus necesidades. Las historias de usuarios también sirven como base para crear tareas y criterios de aceptación durante el proceso de diseño y desarrollo.

## Módulo 2: Flujo de usuario

El Módulo 2 introduce el **Flujo de Usuario**, que es un diagrama o representación visual que muestra el recorrido que un usuario sigue al interactuar con un producto o servicio para completar una tarea específica. Este flujo incluye cada paso, pantalla, acción y decisión que el usuario toma desde el inicio hasta el final del proceso.  

![alt text](../3.%20Creating%20a%20story-based%20design/Images/modulo2.png)

## Módulo 3: Bocetos de soluciones

El Módulo 3 se enfoca en la creación de **Bocetos de Soluciones**, que son representaciones rápidas y básicas de ideas de diseño, generalmente dibujadas a mano o con herramientas digitales simples. Su propósito es visualizar conceptos y posibles soluciones sin invertir demasiado tiempo o recursos.  

![alt text](../3.%20Creating%20a%20story-based%20design/Images/modulo3.png)

## Módulo 4: Caso práctico crear Historias de Usuario y Bocetos de Soluciones

El Módulo 4 presenta un caso práctico donde se aplican dos técnicas esenciales del diseño UX: **Historias de Usuario** y **Bocetos de Soluciones**.  

- **Creación de Historias de Usuario:** Se identifican necesidades específicas de los usuarios y se redactan historias claras y concisas para orientar el diseño.  
- **Bocetos de Soluciones:** Basándose en las historias de usuario, se generan bocetos que representen posibles interfaces o interacciones que resuelvan los problemas detectados.
