# EVIDENCIA ACTIVIDAD DESARROLLO DE SITIOS PARA LA WEB 

## Módulo 1: Exploradores web y marcado

El módulo 1, introduce los fundamentos del funcionamiento de los exploradores web y el marcado HTML. A lo largo del módulo, se explora cómo los navegadores interpretan el código HTML para representar las páginas web en la pantalla del usuario. Se profundiza en los diferentes tipos de marcado y las mejores prácticas para estructurar un documento HTML eficazmente, asegurando la accesibilidad y compatibilidad en distintos dispositivos.

![alt text](../2.%20Web%20site%20development/images/modulo1.png)

## Módulo 2: HTML: el lenguaje de la web
  
Este módulo se centra en **HTML** (HyperText Markup Language), el lenguaje fundamental para la creación de páginas web. A lo largo del módulo, los estudiantes aprenderán cómo estructurar y organizar contenido utilizando etiquetas HTML, desde las más básicas hasta las más avanzadas. Se exploran elementos como encabezados, párrafos, enlaces, listas y tablas, así como el uso adecuado de atributos para mejorar la accesibilidad y la interacción con los usuarios.

![alt text](../2.%20Web%20site%20development/images/modulo2.png)

## Módulo 3: HTML5: la evolución del hipertexto

Este módulo explora **HTML5**, la versión más reciente y avanzada del lenguaje HTML. A lo largo del módulo, se examinan las nuevas características y mejoras de HTML5, como nuevas etiquetas semánticas, soporte multimedia (audio y video), y APIs para el desarrollo de aplicaciones web más interactivas. Se profundiza en la creación de formularios avanzados, la integración de gráficos con el elemento `<canvas>`, y el almacenamiento local en el navegador.

![alt text](../2.%20Web%20site%20development/images/modulo3.png)

## Módulo 4: Función de CSS: aplicar estilo a páginas web
 
Este módulo aborda **CSS**, el lenguaje utilizado para definir la apariencia visual de las páginas web. A lo largo del módulo, los estudiantes aprenderán cómo aplicar estilos a los elementos HTML mediante propiedades como colores, fuentes, márgenes y alineación. Se exploran conceptos clave como el modelo de caja (box model), el uso de clases e ID para seleccionar elementos, y la creación de diseños responsivos con media queries. Además, se profundiza en la importancia de mantener una separación clara entre contenido (HTML) y presentación (CSS) para una mayor organización y mantenibilidad.

![alt text](../2.%20Web%20site%20development/images/modulo4.png)

## Módulo 5: Función de JavaScript: interacción

Este módulo se enfoca en **JavaScript**, el lenguaje de programación que permite agregar interactividad y dinamismo a las páginas web. A lo largo del módulo, los estudiantes aprenderán cómo usar JavaScript para responder a las acciones del usuario, como clics, desplazamientos y entradas de teclado. Se exploran conceptos clave como manipulación del DOM (Document Object Model), eventos, validación de formularios, y el uso de funciones y condicionales para crear comportamientos interactivos. Además, se cubre la integración de JavaScript con HTML y CSS para crear experiencias web más fluidas y atractivas.

![alt text](../2.%20Web%20site%20development/images/modulo5.png)

## Módulo 6: De los requisitos al lanzamiento

Este módulo aborda el proceso completo de desarrollo web, desde la recopilación de los requisitos hasta el lanzamiento final del sitio. A lo largo del módulo, los estudiantes aprenderán a identificar las necesidades del cliente y los usuarios, definir los objetivos del proyecto, y crear una planificación adecuada. Se exploran las fases del desarrollo, incluyendo el diseño, la programación, las pruebas y la implementación. Además, se enfoca en las mejores prácticas para garantizar la calidad del producto, la optimización para diferentes dispositivos y navegadores, y la importancia de realizar pruebas de usabilidad antes del lanzamiento.
