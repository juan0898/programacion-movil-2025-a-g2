# Git y GitHub para Contribuidores de Kubernetes

## Introducción

Esta guía de IBM Developer explica cómo usar Git y GitHub para contribuir eficazmente al proyecto Kubernetes, cubriendo desde configuraciones iniciales hasta buenas prácticas para contribuir en proyectos open source.

## Requisitos Previos

- Conocimientos básicos de Git.
- Cuenta activa en GitHub.
- Configuración local de Git.

## Comandos y Flujo de Trabajo

- **Clonar repositorios**: `git clone`
- **Crear ramas**: `git checkout -b nombre_rama`
- **Agregar cambios**: `git add`, `git commit`
- **Actualizar repositorio remoto**: `git push origin nombre_rama`
- **Sincronizar con upstream**: `git fetch upstream`, `git rebase`

## Pull Requests y Revisión

- Crea una *pull request* desde tu fork.
- Asegúrate de seguir las convenciones del proyecto.
- Participa en la revisión de código con comentarios claros y constructivos.

## Buenas Prácticas

- **Commits pequeños y descriptivos**
- **Uso de ramas por feature o corrección**
- **Actualización frecuente desde el repositorio principal (upstream)**
- **Cumplir con las guías de estilo y pruebas**
