# EVIDENCIA ACTIVIDAD CREACIÓN DE SITIOS WEB DINÁMICOS CON JavaScript

## Módulo 1: La web dinámica: una introducción a JavaScript

El Módulo 1 **La web dinámica: una introducción a JavaScript** presenta los fundamentos esenciales de JavaScript y cómo este lenguaje puede transformar un sitio web estático en una experiencia interactiva y dinámica. A lo largo del módulo, se exploran conceptos clave como variables, operadores, funciones y estructuras de control, permitiendo a los estudiantes entender cómo JavaScript interactúa con el contenido HTML y CSS para crear páginas web más interactivas.

![alt text](../4.%20Creating%20dynamic%20websites%20with%20JavaScript/images/modulo1.png)

## Módulo 2: El modelo de programación JavaScript

El Módulo 2 **El modelo de programación JavaScript** profundiza en los principios y estructuras que gobiernan el funcionamiento interno de JavaScript, centrando la atención en el modelo de ejecución, el manejo de eventos y la asincronía. A través de este módulo, los estudiantes aprenderán sobre el ciclo de vida de un script, el modelo de ejecución de un solo hilo, y cómo se manejan las tareas asíncronas mediante promesas y callbacks. También se abordan conceptos como el event loop y la pila de ejecución, permitiendo a los desarrolladores comprender cómo JavaScript maneja múltiples operaciones simultáneas sin bloquear el flujo de la aplicación. 

![alt text](../4.%20Creating%20dynamic%20websites%20with%20JavaScript/images/modulo2.png)

## Módulo 3: Descripción general de la estructura JavaScript

El Módulo 3 **Descripción general de la estructura JavaScript** ofrece una visión detallada de los componentes clave que forman la estructura de un programa en JavaScript. A lo largo del módulo, los estudiantes explorarán cómo se organizan y estructuran los archivos JavaScript, incluyendo la declaración de variables, el uso de funciones, objetos, arreglos y la implementación de módulos para una mejor organización del código. También se revisan las mejores prácticas para escribir código limpio y mantenible, como la correcta definición de funciones, el manejo adecuado de errores y la organización del flujo de ejecución. 

![alt text](../4.%20Creating%20dynamic%20websites%20with%20JavaScript/images/modulo3.png)

## Módulo 4: Interactuar con los datos

El Módulo 4 **Interactuar con los datos** se centra en cómo JavaScript puede manipular y gestionar datos dentro de una aplicación web. A través de este módulo, los estudiantes aprenderán a trabajar con diferentes tipos de datos, como cadenas de texto, números, objetos y arreglos, y cómo utilizarlos para realizar operaciones dinámicas en el sitio web. Se cubren técnicas de acceso, modificación y eliminación de datos, así como el uso de métodos y funciones específicas para manipular arreglos y objetos. Además, se exploran los conceptos de almacenamiento local (localStorage) y cookies, lo que permite persistir datos entre sesiones de usuario. 

![alt text](../4.%20Creating%20dynamic%20websites%20with%20JavaScript/images/modulo4.png)

## Módulo 5: Ejecución: introducción a Node.js

El Módulo 5 **Ejecución: introducción a Node.js** introduce a los estudiantes en el entorno de ejecución de JavaScript en el lado del servidor mediante Node.js. A lo largo del módulo, se exploran los fundamentos de Node.js, cómo instalarlo y configurarlo, así como sus características clave, como el modelo de programación asíncrono y no bloqueante. Los estudiantes aprenderán a crear servidores básicos, manejar rutas y trabajar con archivos y bases de datos de manera eficiente. Además, se presentan las ventajas de utilizar Node.js para desarrollar aplicaciones escalables y de alto rendimiento, destacando su ecosistema de módulos y su capacidad para manejar múltiples solicitudes concurrentes.
