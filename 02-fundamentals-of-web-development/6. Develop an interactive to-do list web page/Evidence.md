# EVIDENCIA ACTIVIDAD DESARROLLAR UNA PÁGINA WEB DE LISTA DE TAREAS INTERACTIVE

## Módulo 1: ¡Es un desarrollador web!

El Módulo 1 introduce el rol del desarrollador web en el contexto del diseño centrado en el usuario. A lo largo del módulo, se exploran las responsabilidades clave de este perfil profesional y su relación con la experiencia de usuario (UX). Se abordan conceptos fundamentales como la accesibilidad, la usabilidad y la importancia de crear interfaces intuitivas. Además, se analiza cómo un desarrollador puede colaborar eficazmente con diseñadores UX para transformar ideas en productos funcionales y centrados en el usuario. 

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo1.png)

## Módulo 2: ¡Inicie su proyecto!

El Módulo 2 se enfoca en los pasos iniciales para poner en marcha un proyecto de diseño centrado en el usuario. Se destacan las actividades clave para definir el propósito del producto, comprender a los usuarios y establecer objetivos claros. A través de ejemplos prácticos, se enseña cómo formular preguntas de investigación, identificar necesidades del público objetivo y delimitar el alcance del proyecto.

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo2.png)

## Módulo 3: Configurar una página web con HTML

El Módulo 3 introduce los fundamentos de HTML como herramienta esencial para estructurar el contenido de una página web. A lo largo del módulo, se guía al estudiante en la creación de una página básica utilizando etiquetas semánticas que mejoran la accesibilidad y la experiencia del usuario. Se explican conceptos clave como encabezados, párrafos, enlaces, listas, imágenes y formularios, destacando su importancia en la organización del contenido.

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo3.png)

## Módulo 4: Aplicar estilos con CSS

El Módulo 4 se centra en el uso de CSS para mejorar la apariencia visual y la experiencia del usuario en una página web. Se exploran los principios básicos del diseño visual, incluyendo el uso del color, la tipografía, el espaciado y el diseño responsivo. A través de ejercicios prácticos, se enseña cómo aplicar estilos a elementos HTML, crear diseños atractivos y mantener la coherencia visual. Este módulo destaca cómo el CSS no solo embellece la interfaz, sino que también contribuye a una experiencia de usuario más agradable, accesible y funcional.

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo4.png)

## Módulo 5: Añadir interactividad con JavaScript

El Módulo 5 introduce JavaScript como herramienta clave para dotar de interactividad a las páginas web. A lo largo del módulo, se enseñan los fundamentos del lenguaje y su aplicación para responder a las acciones del usuario, manipular el DOM y mejorar la experiencia en tiempo real. Se presentan ejemplos prácticos como validaciones de formularios, respuestas a eventos y actualizaciones dinámicas de contenido.

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo5.png)

## Módulo 6: Probar una página web

El Módulo 6 aborda la importancia de evaluar una página web mediante pruebas centradas en el usuario. Se exploran diferentes métodos de prueba, como pruebas de usabilidad, revisión heurística y pruebas funcionales, para identificar problemas que puedan afectar la experiencia del usuario. A través de ejemplos y herramientas prácticas, se enseña cómo recopilar retroalimentación, analizar resultados y realizar mejoras iterativas. El objetivo es garantizar que la página web sea accesible, intuitiva y cumpla con las expectativas del público objetivo, integrando la evaluación continua como parte del proceso de diseño UX.

![alt text](../6.%20Develop%20an%20interactive%20to-do%20list%20web%20page/images/modulo6.png)
