# EVIDENCIA ACTIVIDAD PRUEBA Y DESPLIEGUE DE SITIOS WEB

## Módulo 1: Prueba de un sitio web

EL módulo 1 se enfoca en las diferentes técnicas y metodologías para realizar pruebas efectivas en un sitio web. A lo largo del módulo, se exploran los tipos de pruebas más relevantes, como las pruebas funcionales, de rendimiento, de usabilidad y de seguridad. Se enseñará a identificar errores comunes en el diseño y funcionalidad del sitio, así como a evaluar la experiencia del usuario en diferentes dispositivos y navegadores.

## Módulo 2: Seguimiento y gestión de cambios del código

El módulo 2 se centra en la importancia de implementar un sistema de control de versiones para gestionar los cambios en el código fuente de un proyecto. A lo largo del módulo, se abordan herramientas y prácticas clave, como Git, que permiten a los desarrolladores realizar un seguimiento eficiente de las modificaciones, colaborar de manera efectiva y mantener un historial claro de los cambios realizados. Se cubren conceptos como ramas, commits, fusiones y resolución de conflictos, con el objetivo de mejorar la colaboración dentro del equipo y garantizar la integridad del código durante todo el ciclo de desarrollo. 

![alt text](../5.%20Website%20testing%20and%20deployment/images/modulo2.png)

## Módulo 3: Entrega de un sitio web a los usuarios

El módulo 3 se enfoca en el proceso de entrega de un sitio web desde su fase de desarrollo hasta su disponibilidad para los usuarios finales. A lo largo del módulo, se exploran los pasos clave para garantizar un despliegue exitoso, incluyendo la preparación del entorno de producción, la migración de datos, la configuración de dominios y servidores, y la implementación de medidas de seguridad. Se discute la importancia de realizar pruebas finales en un entorno de transferencia para asegurar que todo funcione correctamente antes del lanzamiento. Además, se abordan aspectos como la monitorización post-lanzamiento y la gestión de errores, con el objetivo de ofrecer una experiencia fluida y segura a los usuarios.

![alt text](../5.%20Website%20testing%20and%20deployment/images/modulo3.png)

## Módulo 4: Entrega de sitios web a todos los dispositivos

El módulo 4 se centra en la optimización y entrega de un sitio web para que funcione de manera eficiente en una amplia variedad de dispositivos, incluyendo computadoras de escritorio, tabletas y teléfonos móviles. A lo largo del módulo, se exploran estrategias de diseño responsivo (responsive design) y se profundiza en cómo adaptar el contenido, la navegación y las funcionalidades del sitio para ofrecer una experiencia de usuario consistente y de alta calidad, sin importar el tamaño o tipo de dispositivo. Se abordan técnicas de pruebas de compatibilidad y rendimiento en múltiples plataformas, asegurando que el sitio web cargue rápidamente y sea accesible en todos los dispositivos. 

![alt text](../5.%20Website%20testing%20and%20deployment/images/modulo4.png)

## Módulo 5: Servicios y herramientas para las pruebas y el despliegue

El módulo 5 explora una variedad de servicios y herramientas que facilitan el proceso de pruebas y despliegue de sitios web. Se cubren plataformas y herramientas automatizadas que ayudan a realizar pruebas de rendimiento, funcionalidad, usabilidad y seguridad de manera eficiente. Además, se introduce el concepto de integración continua y entrega continua (CI/CD), que optimiza el proceso de despliegue al permitir actualizaciones rápidas y seguras. El módulo también aborda herramientas de monitorización post-lanzamiento, que aseguran que el sitio se mantenga operativo y libre de errores tras su despliegue. 

![alt text](../5.%20Website%20testing%20and%20deployment/images/modulo5.png)

## Módulo 6: Despliegue en la nube

El módulo 6 se centra en las mejores prácticas y herramientas para desplegar sitios web en la nube. A lo largo del módulo, se exploran los beneficios de la infraestructura en la nube, como la escalabilidad, la flexibilidad y la capacidad de distribuir el contenido globalmente. Se aborda cómo configurar y gestionar servidores en la nube, así como las opciones disponibles en plataformas como AWS, Azure y Google Cloud. También se profundiza en el uso de servicios de nube para la integración continua y la entrega continua (CI/CD), facilitando despliegues automáticos y rápidos.
