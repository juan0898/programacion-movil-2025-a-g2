# EVIDENCIA ACTIVIDAD INTRODUCCIÓN A HTML Y CSS

## Módulo 1: Configurar una página web con HTML

El Módulo 1 **Configurar una página web con HTML** introduce los fundamentos del desarrollo web, centrando la atención en la estructura básica de una página web utilizando **HTML**. A lo largo del módulo, los estudiantes aprenderán cómo crear la estructura de una página web mediante el uso de etiquetas HTML, cómo organizar el contenido en secciones, y cómo agregar elementos esenciales como encabezados, párrafos, enlaces e imágenes. También se abordarán buenas prácticas en la escritura de código HTML y se explicará la importancia de la accesibilidad y la semántica en el desarrollo web. 

![alt text ](../3.%20Introduction%20to%20HTML%20and%20CSS/images/modulo1.png)

## Módulo 2: Controlar elementos con atributos

El Módulo 2 **Controlar elementos con atributos** profundiza en el uso de **atributos HTML** para modificar y personalizar el comportamiento y la presentación de los elementos en una página web. A lo largo del módulo, se explora cómo aplicar atributos comunes como `href`, `src`, `alt`, `class`, `id`, entre otros, para mejorar la funcionalidad y accesibilidad del contenido. Además, se enseña cómo los atributos permiten vincular recursos externos, identificar elementos para aplicar estilos o scripts, y proporcionar información adicional que enriquece la experiencia del usuario. 

![alt text](../3.%20Introduction%20to%20HTML%20and%20CSS/images/modulo2.png)

## Módulo 3: Organizar el código

El Módulo 3 **Organizar el código** se enfoca en la importancia de mantener un código HTML claro, estructurado y fácil de mantener. Durante el módulo, se enseñan técnicas para mejorar la legibilidad del código, como la indentación adecuada, el uso de comentarios, la separación lógica de secciones y el uso coherente de nombres en clases e identificadores. También se abordan buenas prácticas para facilitar la colaboración en equipo y la escalabilidad de los proyectos web.

![alt text](../3.%20Introduction%20to%20HTML%20and%20CSS/images/modulo3.png)

## Módulo 4: Codificar con estilo: utilizar CSS

El Módulo 4 **Codificar con estilo: utilizar CSS** introduce el uso de **CSS (Cascading Style Sheets)** para aplicar estilos a las páginas web y mejorar su apariencia visual. A lo largo del módulo, se explora cómo seleccionar elementos HTML mediante selectores y cómo aplicarles propiedades de estilo como colores, fuentes, márgenes, bordes y alineación. También se enseña la diferencia entre estilos en línea, internos y externos, y se promueven buenas prácticas para mantener una separación clara entre contenido y presentación. 

![alt text](../3.%20Introduction%20to%20HTML%20and%20CSS/images/modulo4.png)

## Módulo 5: Modelo de cuadro CSS

El Módulo 5 **Modelo de cuadro CSS** se centra en uno de los conceptos fundamentales del diseño web: el modelo de caja de CSS. En este módulo, se analiza cómo cada elemento HTML se representa como una caja rectangular compuesta por márgenes, bordes, relleno y contenido. Se explica cómo manipular cada una de estas propiedades para controlar el espacio, la alineación y la disposición de los elementos en la página. Además, se muestran ejemplos prácticos para comprender cómo el modelo de cuadro influye en el diseño responsivo y en la interacción entre distintos componentes visuales.

![alt text](../3.%20Introduction%20to%20HTML%20and%20CSS/images/modulo5.png)

## Módulo 6: Buenas prácticas para escribir HTML y CSS

El Módulo 6 **Buenas prácticas para escribir HTML y CSS** aborda los principios clave para desarrollar código limpio, eficiente y fácil de mantener. A lo largo del módulo, se presentan recomendaciones para estructurar correctamente documentos HTML, aplicar estilos CSS de forma organizada y evitar errores comunes. Se enfatiza la importancia del uso de etiquetas semánticas, la separación entre contenido y presentación, la reutilización de clases, el uso coherente de nombres y la documentación mediante comentarios.
