## Módulo 1: ¿Cómo funciona un ordenador?

El Módulo 1 ofrece una introducción al **funcionamiento interno de un ordenador**, explicando de manera sencilla cómo los componentes físicos y lógicos trabajan en conjunto para procesar información. Se abordan conceptos clave como hardware, software, memoria, CPU y sistemas operativos, destacando el papel que cada uno desempeña en la ejecución de tareas. A lo largo del módulo, se busca desarrollar una comprensión básica pero sólida del entorno tecnológico que sustenta el desarrollo digital. 

![alt text](../1.%20Web%20Development%20Basics/images/modulo1.png)

## Módulo 2: Hablemos del código 

El Módulo 2 se centra en entender el código como el lenguaje detrás de las aplicaciones digitales. A lo largo del módulo, se introduce la lógica básica de la programación, los tipos de lenguajes más utilizados y la forma en que el código da vida a las funcionalidades que experimentan los usuarios. Se exploran conceptos esenciales como variables, estructuras de control, funciones y sintaxis, brindando una base sólida para quienes se inician en el mundo del desarrollo. 

![alt text](../1.%20Web%20Development%20Basics/images/modulo2.png)

## Módulo 3: ¿Qué es el desarrollo web?

El Módulo 3 introduce el concepto de **desarrollo web**, proporcionando una visión general sobre cómo se crean y estructuran los sitios y aplicaciones en línea. Se abordan los componentes fundamentales del desarrollo web, incluyendo el front-end, el back-end y las bases de datos, así como el rol que cada uno cumple en la construcción de experiencias digitales. A lo largo del módulo, se analizan las diferencias entre desarrollo web estático y dinámico, y se contextualiza la evolución del desarrollo web en el entorno actual. 

![alt text](../1.%20Web%20Development%20Basics/images/modulo3.png)

## Módulo 4: Desarrollo front-end

El Módulo 4 se enfoca en el **desarrollo front-end**, abordando los fundamentos para construir interfaces de usuario interactivas, accesibles y visualmente atractivas. A lo largo del módulo, se exploran tecnologías clave como HTML, CSS y JavaScript, así como frameworks modernos que optimizan la creación de aplicaciones web. Se destaca la importancia de diseñar con enfoque en la experiencia del usuario, garantizando navegabilidad, usabilidad y adaptabilidad en distintos dispositivos.

![alt text](../1.%20Web%20Development%20Basics/images/modulo4.png)

## Módulo 5: Desarrollo back-end

El Módulo 5 está dedicado al **desarrollo back-end**, centrándose en la lógica y estructura que permite que las aplicaciones web funcionen correctamente detrás de escena. Se exploran temas como servidores, bases de datos, APIs y lenguajes de programación del lado del servidor, mostrando cómo se gestionan los datos y se responde a las solicitudes del usuario. A lo largo del módulo, se destaca la importancia de la seguridad, la eficiencia y la escalabilidad en el desarrollo de soluciones robustas. 

![alt text](../1.%20Web%20Development%20Basics/images/modulo5.png)

## Módulo 6: Una red de redes

El Módulo 6 explora el concepto de **Una red de redes**, explicando cómo se comunican los dispositivos a nivel global para compartir información. Se abordan fundamentos de redes informáticas, incluyendo protocolos como TCP/IP, direcciones IP, DNS y el funcionamiento de servidores y navegadores. A lo largo del módulo, se analiza cómo fluye la información en la web y qué elementos intervienen en una conexión exitosa.

![alt text](../1.%20Web%20Development%20Basics/images/modulo6.png)
